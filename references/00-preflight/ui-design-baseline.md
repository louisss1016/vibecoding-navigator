# UI 设计基线：别让页面白得发光

> 本文件是前端切片的**设计底线**，不是设计教程。目标：AI 写出来的页面不该是"白底 + 默认字号 + 无排版"的demo 相。派工单涉及任何界面时，先过本文件的最小检查清单。

## 为什么 AI 写的前端特别"白"

三个原因叠加，逐一对策：

1. **Tailwind/unocss 默认无样式**——工具类只提供能力，不提供决策。AI 不主动选字号、色板、间距，产出就是浏览器默认（白底、16px Times/系统字体、左对齐顶格）。
2. **AI 的保守偏向**——不确定时选最安全的（白底、灰字、默认圆角），结果是没有层级、没有重点、没有呼吸感。
3. **需求里没写设计要求**——派工单只说"做个列表页"，没说信息密度、视觉重点、品牌色，AI 只能交白卷。

**对策：把设计决策写进派工单和切片验收，不留白。**

## 设计基线（每个前端切片的最低标准）

### 1. 字号阶梯，不许一页一个号

至少四档，全站统一（示例值，按项目微调）：

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 20–24px | 600–700 |
| 卡片/区块标题 | 16–18px | 600 |
| 正文 | 14px | 400 |
| 辅助/次要信息 | 12–13px | 400，颜色降级 |

标题 > 正文 > 辅助，一眼能分出主次。全页一种字号 = 没有信息架构。

### 2. 行高与间距节奏

- 正文行高 1.5–1.75；标题行高 1.2–1.3。
- 间距用**阶梯**不用随手值：4 的倍数（4/8/12/16/24/32/48）。同层级元素间距必须一致——卡片内 16、卡片间 24、区块间 48，节奏比数值重要。
- 内容不要顶格：页面级 padding 至少 24px，表单/表格周边留白是"排版"的一半。

### 3. 色彩：中性色带色相，主色只有一个

- **背景不用纯白 #fff**：用带一点点色相的中性色（如 slate-50 / gray-50 一类），纯白是"没调过"的标志。
- 文字不用纯黑 #000：用深灰（gray-800/900 一类），长文本阅读不刺眼。
- 主色（品牌/行动色）全站**只有一个**，用于主要按钮、链接、选中态；其余颜色克制。Tailwind 默认蓝、Element Plus 默认亮蓝都很"demo"——项目要么定制主题色，要么明确接受默认并写进 ARCHITECTURE。
- 语义色固定四件套：成功绿、警告黄、错误红、信息蓝/主色，全站一致，不新造。

### 4. 布局：视觉层级 > 栅格教条

- 先定**视觉动线**：用户第一眼看哪（最大/最亮/最上的元素），第二眼看哪。每页只允许一个视觉主角。
- 对齐是底线：同一区块的元素共享一条对齐线（左对齐或居中，不混用）。间距不匀比颜色丑更致命。
- 列表/表格：行高一致、斑马纹或分隔线二选一、表头加重、数字右对齐、操作列固定右侧。
- 空状态、加载态、错误态是页面的一部分，不是补丁——见 `references/02-postflight/product-states.md` 的六种产品状态。

### 5. 组件完成度

- 交互元素必须有 hover / focus-visible / disabled / active 四态；focus 态不许 `outline: none` 裸奔（可访问性红线）。
- 圆角、阴影、边框全站统一规格（如圆角 6/8 两档、阴影一档），不一个页面一个样。
- 暗色模式 MVP 可以不做，但颜色必须走 token（CSS 变量/Tailwind config），想加时改 token 不改组件。

## 反面模式（出现任何一个，打回）

1. 纯白背景 + 纯黑正文 + 全页 16px 一种字号
2. 元素间距随手写（7px、13px、18px……不在阶梯上）
3. 主要按钮和次要按钮长得一样（没有视觉主次）
4. 表格无表头强调、无斑马纹/分隔线、数字左对齐
5. 页面内容顶格（无 padding），或卡片内元素贴边
6. 链接和正文一个色（分不清哪里能点）
7. 空页面就是一片空白，没有空状态引导

## 切片前最小检查（派工单里逐条过）

- [ ] 字号阶梯定了吗（标题/正文/辅助至少三档）？
- [ ] 间距阶梯定了吗（4 的倍数）？
- [ ] 背景/文字/主色/语义色四个 token 定了吗？
- [ ] 这一页的视觉主角是谁？
- [ ] 空态/加载态/错误态有落点吗？

五条全过再派工。设计决策同步写进 ARCHITECTURE.md 的"设计约束"section，不要只活在这一次对话里。

## 什么时候不用管本文件

- 纯后端切片（API、脚本、迁移）——没有 UI
- CLI 工具——终端输出不适用排版体系
- 明确只要功能验证的原型（但交活标准仍是"能看"，不是"白得发光"）
